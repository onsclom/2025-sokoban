# 2025-sokoban

https://sokoban.xyz

Controls: WASD or arrow keys to move, u to undo, r to restart.

Project made for Hack Vegas 2025 hackathon. Code was written in less than 48 hours! All graphics and sounds are procedural, making the site's total asset size less than 20 kB!

## Development

Requires [Bun](https://bun.sh).

```sh
bun install        # install dependencies
bun dev            # start the dev server
bun run build      # build to dist/
bun run preview    # serve the built dist/
```
